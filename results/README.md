# Released experiment results

`tables/` contains aggregate paper tables. Reported means are across four test
forecast origins; PINN means additionally average three seeds within origin.

`matrices/` contains the Neighbor Network and Data-Inferred Network coupling
matrices averaged across 12 fits, their elementwise difference, a county FIPS
lookup, and aggregate distance diagnostics. Per-run matrices are excluded.

No county-week observations, predictions, outside signals, or latent state
trajectories are stored here.
