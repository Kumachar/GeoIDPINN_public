# Notebooks

The notebooks are in English, contain no saved outputs, and use repository-
relative paths.

- `01_all64_model_comparison.ipynb`: Neighbor Network, identity-fixed No County
  Network, and NB-AR test metrics.
- `02_spatial_prior_sensitivity.ipynb`: all-64 MSE across 11 priors.
- `03_learned_matrix_comparison.ipynb`: mean matrix heatmaps and distance
  diagnostics.
- `04_paper_results_index.ipynb`: compact view of every released paper table.
- `05_synthetic_identifiability_experiment.ipynb`: self-contained synthetic
  known-truth experiment; this notebook is substantially more expensive.

The first four notebooks require only files committed to this repository.
